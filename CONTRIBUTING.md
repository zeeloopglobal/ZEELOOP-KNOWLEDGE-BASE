
# Contributing to Zeeloop Engineering Knowledge

Thank you for contributing!

## 1. Documentation Format

- Use Markdown (.md).
- Use descriptive file and folder names.
- Follow the templates provided.
- Write clear, professional, technically accurate content.

## 2. Where to Add Documentation

- technologies/ - General technology documentation.
- research/ - Technical research and comparisons.
- reusable-solutions/ - Reusable implementations and solutions.
- glossary/ - Technical terminology.

## 3. Documentation Requirements

- Explain concepts clearly.
- Include practical examples where possible.
- Provide reliable references.
- Include relevant limitations and trade-offs.
- Include the last reviewed date.

## 4. Security and Confidentiality

Never publish:
- API keys, passwords, or access tokens.
- Client-specific confidential information.
- Private source code or configurations.
- Personal or sensitive information.
- Proprietary business information.

## 5. Contribution Workflow

1. Create a feature branch.
2. Add or update documentation.
3. Review your changes.
4. Submit a Pull Request.
5. Obtain approval from another team member.
6. Merge into main.

## 6. Quality Standards

Contributions should be:
- Accurate
- Understandable
- Well structured
- Properly referenced
- Useful to other developers

Thank you for helping build Zeeloop's
engineering knowledge base!
